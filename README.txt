编导拍播培训 · 课程看板 —— 局域网部署说明
================================================

一、这台电脑需要先装 Node.js（只装一次）
------------------------------------------------
1. 打开 https://nodejs.org/ ，下载 LTS 版（Windows 安装包，.msi）
2. 一路「下一步」装完，不需要改任何选项
3. 装完后关掉所有命令行窗口（新窗口才会认到 node）

二、启动看板
------------------------------------------------
双击文件夹里的「启动看板.bat」。
- 会弹出一个黑色窗口，里面写着两个地址：
      本机    http://127.0.0.1:8088
      局域网  http://<这台电脑的IP>:8088
- 局域网地址就是发给同事的那个，同一网络的电脑、手机浏览器都能打开
- 黑色窗口不要关，关了服务就停；要停的时候直接关窗口即可

三、端口说明
------------------------------------------------
本机 8080 已被别的程序占用，所以看板用 8088。
如果 8088 也被占用，用记事本打开「启动看板.bat」，
把里面的 set PORT=8088 改成别的数字（例如 8090）再启动即可。

四、防火墙
------------------------------------------------
第一次启动时 Windows 可能弹「是否允许 Node.js 访问网络」，
一定要勾选「专用网络」并点「允许访问」，否则其它电脑打不开。
如果当时点了取消：控制面板 → 系统和安全 → Windows Defender 防火墙
→ 允许应用通过防火墙 → 找到 Node.js → 勾上「专用」。

五、数据存在哪
------------------------------------------------
课程数据在子文件夹 data\courses.json，
每次保存/上传都会在 data\backup\ 里留一份上一版的备份。
想备份整个看板，把整个文件夹拷走即可。

六、日常维护
------------------------------------------------
- 改课程：打开看板 → 右上角「编辑课程」，或打开「拖动编辑」直接拖日期
- 换课表：右上角「上传课程表」，传 Word（.docx）即可
- 推送到公网：编辑模式下点「推送上线」（需要先配一次 GitHub 令牌）
