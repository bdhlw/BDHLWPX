上传新的课程表

上传 .docx 课程安排，看板会自动重新读取并覆盖当前数据

  • 文档里需要有表格，且四列含义为：时间（含「2026年11月10日 周二」）、培训项目名称、授课教师、参与学生人数。
  • 时间列里写了「17:30-19:30」会自动识别为上课时段，没写则显示为「待定」。
  • 方向按课程名关键词自动归类（膳食 / 工作坊 / 自媒体IP）；试听、动员会、宣讲会归入「公共课程」，只计入总数、不参与方向进度。上传后可在「编辑课程」里手动改。
  • 上传前的版本会自动备份到 data/backup/，误传可从历史数据恢复。
